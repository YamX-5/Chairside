# Surface textures (drop generated art here)

Seamless, tileable textures mapped onto the clinic's walls, floor, wood and
fabric. See `GENERATION_BRIEF.md` in the project root for exact prompts.

Expected filenames (missing files fall back to flat colour automatically):

- `wall.jpg` — warm cream plaster wall
- `floor.jpg` — pale warm stone / tile floor
- `wood.jpg` — honey-toned wood (desk, dado, furniture)
- `fabric.jpg` — teal upholstery (dental chair)
- `cork.jpg` — cork noticeboard (optional)

Requirements: **seamless / tileable**, flat even top-down lighting (no baked
shadows or perspective), stylized low-poly / Pixar palette, ~1024×1024px, JPG.
